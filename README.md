# Pig-Genocide

2D платформер с процедурной генерацией, разрушаемым окружением, адаптивной сложностью и умными врагами на A*. 
Игрок может паррировать, стрелять, взрывать.

## Технологии

Unity 2022.3+
C# / .NET
VContainer (DI)

---

## Архитектура

**ILevelGenerator** процедурная генерация

**IPathFinder** A* поиск пути

**IPlayerProvider** доступ к игроку через DI

**IInvoker** повторяющиеся действия (спавн, апдейты)
